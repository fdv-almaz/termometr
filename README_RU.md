# Термометр - Система удаленного мониторинга температуры через WiFi

Распределённая система мониторинга температуры в доме с использованием микроконтроллеров ESP32, веб-сервера и электронных дисплеев e-ink.

## 🎯 Особенности

- **Двухканальное измерение температуры** (улица и дом)
- **Мониторинг атмосферного давления** через датчик BMP280
- **Маломощный e-ink дисплей** для удаленного просмотра
- **Поддержка нескольких датчиков** через конфигурацию EEPROM
- **Настраиваемые коррекции температуры** в базе данных
- **Защищённый API** с аутентификацией
- **Режим глубокого сна** для питания от батареи

## 📋 Требования

### Оборудование

- **Плата датчиков**: ESP32 + DS18B20 (×2) + BMP280
- **Плата дисплея**: ESP32 + e-ink дисплей GxEPD 2.13" (TTGO T5 V2.4.1+)
- **Сервер**: Linux с Apache/Nginx и PHP 7.4+
- **База данных**: MySQL 5.7+ или MariaDB 10.3+
- **WiFi сеть**: 2.4 ГГц (ESP32 не поддерживает 5 ГГц)

### ПО

- Arduino IDE 1.8.19+ с поддержкой ESP32 (v2.0.0+)
- PHP 7.4 или новее
- MySQL/MariaDB клиент

### Необходимые библиотеки Arduino

Для платы датчиков:
- `ESP32Time`
- `OneWire`
- `DallasTemperature`
- `Adafruit_BMP280`

Для платы дисплея:
- `GxEPD`
- `GxDEPG0213BN`
- Все зависимости GxEPD

## 🚀 Быстрый старт

### 1. Подготовка базы данных

```bash
# Создать базу данных и пользователя
mysql -u root -p < mysql/meteoDB_create.sql

# Или вручную:
mysql -u root -p
CREATE DATABASE meteo CHARACTER SET utf8mb4;
CREATE USER 'meteo_user'@'localhost' IDENTIFIED BY 'надежный_пароль';
GRANT ALL PRIVILEGES ON meteo.* TO 'meteo_user'@'localhost';
```

### 2. Установка веб-части

```bash
# Скопировать файлы на веб-сервер
cp -r meteo/ /var/www/html/
chown -R www-data:www-data /var/www/html/meteo/
mkdir -p /var/www/html/meteo/logs
chmod 755 /var/www/html/meteo/logs

# Создать файл конфигурации
cp meteo/example.config.php meteo/db.php
# Отредактировать meteo/db.php с вашими параметрами
```

Установить переменные окружения в конфигурацию веб-сервера:

```apache
SetEnv DB_HOST localhost
SetEnv DB_USER meteo_user
SetEnv DB_PASS надежный_пароль
SetEnv DB_NAME meteo
SetEnv API_KEY ваш_секретный_ключ_api
SetEnv ENABLE_AUTH true
```

### 3. Настройка Arduino

1. Установить Arduino IDE и поддержку ESP32
2. Установить требуемые библиотеки через Library Manager
3. **ВАЖНО**: Настроить EEPROM на каждом ESP32 перед загрузкой основного скетча

См. `EEPROM_CONFIG_GUIDE_RU.md` для подробных инструкций.

4. Загрузить скетч платы датчиков на первый ESP32
5. Загрузить скетч платы дисплея на второй ESP32

## 📡 API документация

### GET /meteo/save.php

Сохраняет данные температуры от платы датчиков.

**Параметры**:
- `api_key` (обязательный): Ключ аутентификации
- `dev_id` (обязательный): ID устройства (1-255)
- `time` (опциональный): Время в формате HH:MM:SS
- `temperatureUL` (обязательный): Температура снаружи (-50 до +100°C)
- `temperatureDOM` (обязательный): Температура в доме (-50 до +100°C)
- `press` (опциональный): Давление (300-1200 гПа)

**Пример**:
```
GET /meteo/save.php?api_key=abc123&dev_id=1&time=14:30:45&temperatureUL=5.2&temperatureDOM=21.3&press=1013.25
```

**Ответ**:
```json
{"status": "success", "message": "Data saved"}
```

### GET /meteo/getlast.php

Получает последние данные температуры для дисплея.

**Формат ответа** (CSV):
```
device_id,timestamp,tempInside,tempOutside,corrInside,corrOutside,pressure
```

**Пример**:
```
1,2024-05-08 14:30:45,21.30,5.20,+0.0,-1.5,1013.2
```

## 🔧 Конфигурация

### Коррекции температуры

Коррекции хранятся в таблице `config` и применяются на сервере:

```sql
INSERT INTO config (param_name, param_data, comment) VALUES
('ULcorr', '-1.5', 'Коррекция уличной температуры'),
('DOMcorr', '+0.5', 'Коррекция комнатной температуры'),
('PRESScorr', '-3.0', 'Коррекция давления');
```

### Интервалы сна

- **Плата датчиков**: Установите `sleep_minutes` в коде (по умолчанию: 1 минута между измерениями)
- **Плата дисплея**: Установите `update_interval_minutes` в коде (по умолчанию: 10 минут)

## 📊 Схема базы данных

### Таблица data
- `id`: Первичный ключ с автоинкрементом
- `dev_id`: Идентификатор устройства
- `dev_time`: Время с устройства
- `tempUL`: Температура снаружи
- `tempDOM`: Температура в доме
- `pressure`: Атмосферное давление
- `inserted`: Временная метка сервера

### Таблица config
- `id`: Первичный ключ
- `param_name`: Имя параметра конфигурации
- `param_data`: Значение параметра
- `comment`: Описание

## 🐛 Решение проблем

**Дисплей показывает "No WiFi"**
- Проверьте SSID и пароль в EEPROM
- Убедитесь, что учетные данные WiFi верны
- Проверьте мощность сигнала WiFi (не менее -80 дБм)

**Данные не сохраняются**
- Проверьте ключ API в запросе
- Посмотрите логи ошибок PHP: `/var/www/html/meteo/logs/error.log`
- Проверьте подключение к БД: `mysql -u meteo_user -p meteo -e "SELECT 1"`

**Значения температуры неправильные**
- Проверьте разводку датчиков
- Убедитесь, что есть pull-up резистор 4.7kΩ для DS18B20
- Проверьте адрес I2C для BMP280 (0x76 или 0x77)

**Дисплей показывает старые данные**
- Плата датчиков может иметь проблемы с подключением
- Проверьте связь с сетью
- Убедитесь, что ключ API совпадает в обоих скетчах
